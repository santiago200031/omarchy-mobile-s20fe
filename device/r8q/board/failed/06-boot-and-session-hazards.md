# Failed 06: Boot & Session Bring-Up Hazards

- **Symptom:** Early boot hangs (`serial0 = &uart6`, unguarded `bt-agent`), massive monitor CPU burn (`1h49m` over `8.5h`), session instability (`udisks2` / `voxtype` / `icc_bwmon` / `camcc_sm8250`), and failed transfers (`scp`).
- **Back:** [FAILED.md](../FAILED.md) · [Board Overview](../README.md)

## Root Causes & Permanent Rules
1. **Unprotected `aliases { serial0 = &uart6; }` at early boot & `qcom_geni_serial` `-19`:** `uart6` (`998000.serial`) is the sole last consumer on `gem_noc`/`qup_virt` (and before blacklisting `icc_bwmon`/`camcc_sm8250`, also `aggre1`/`rpmhpd`/`gcc`), so static `/aliases/serial0` hung early boot; meanwhile omitting `/aliases/serial*` caused `of_alias_get_highest_id("serial")` to return `-19` -> `-ENOSPC`. **Rule:** Never trigger `sync_state()` from `&uart6`; clamp `max(of_alias_get_highest_id("serial"), -1)` in kernel (`caa385175`) or load `r8q-bt-uart.ko` (`device_links_supplier_sync_state_pause()`).
2. **`btmgmt` without `--timeout` / missing `CONFIG_BT_LE=y`:** `arm64 defconfig` disables `CONFIG_BT_LE`, and `btmgmt` v5.88 blocks indefinitely in non-interactive shells unless `--timeout` is passed (`btmgmt -i 0 config` also prints `hci62528` when `--index none` isn't used); QCA6390 also stays in `Unconfigured controller` (`missing options: public-address`) until `btmgmt --timeout 3 --index 0 public-addr` sets a BD_ADDR. **Rule:** Enable `CONFIG_BT_LE=y` and always run `timeout N btmgmt --timeout M ... </dev/null`.
3. **`omamobile-r8q-rtc.service` `sysinit.target` ordering cycle (`1975` RTC):** PM8150 RTC resets to `May 1975` on every reboot; declaring `Before=systemd-timesyncd.service` with `DefaultDependencies=yes` (`WantedBy=multi-user.target`) created a systemd dependency cycle that deleted `systemd-timesyncd.service`, breaking `mise` TLS (`certificate not valid yet`) and `pacman-key` (`created in the future`). **Rule:** Use `DefaultDependencies=no`, `WantedBy=sysinit.target`, `Before=sysinit.target time-sync.target systemd-timesyncd.service`, and `ensure_r8q_clock()` in `r8q-liveness-monitor`.
4. **`systemd.unit=multi-user.target` skipping `sddm.service`:** Because `sddm.service` is `PartOf=graphical.target`, recovery cmdline `systemd.unit=multi-user.target` leaves the phone on a black console unless linked in `multi-user.target.wants` and checked by `ensure_r8q_desktop()`.
5. **`r8q-liveness-monitor` `online_cpus | grep`**: Running `online_cpus | grep -qx "$c"` per PID inside the loop triggered a `SIGPIPE` / subshell storm. **Rule:** Read `$SYS/devices/system/cpu/cpu$c/online` directly in shell.
6. **Unready session daemons & clocks**: `udisks2` (probing 77 RO UFS partitions), `voxtype` (147 MB Whisper model autoload), and unpowered `icc_bwmon`/`camcc_sm8250` clocks stressed bring-up. **Rule:** Keep `icc_bwmon` + `camcc_sm8250` blacklisted (`/etc/modprobe.d/omamobile-r8q-bringup.conf`), `udisks2` masked, and `voxtype` disabled until their subsystems are brought up.
7. **12 GB `scp` image copy / trusting Heimdall exit alone**: `scp` died mid-writeback (crash #14), and an older flash left `sda24` stale. **Rule:** Use chunked resumable `tools/r8q-push` and verify `uname -r` after every flash.
